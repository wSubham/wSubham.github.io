## 🚀 Featured Projects

### 1. AI Weapon Detection & Multi-Camera Surveillance System

An AI-powered surveillance system developed for real-time weapon detection, activity recognition, multi-object tracking, person re-identification, and intelligent monitoring.

**Technologies:**

`Python` `YOLO` `YOLO Pose` `OpenCV` `ByteTrack` `DeepSORT` `OSNet`

**Key Features:**

* Real-time pistol and knife detection
* Human pose-based activity recognition
* Multi-object tracking
* Weapon-person association
* Suspect identification
* Person re-identification
* Cross-camera identity tracking
* Evidence snapshot generation
* Activity monitoring
* Heatmap generation

This project was developed as a **B.Tech final-year project in Computer Science & Engineering (Artificial Intelligence & Machine Learning).**

---

### 2. Real-Time Crowd Activity Detection & Heatmap Analysis

A computer vision-based system designed to analyze crowd activity and visualize areas of higher and lower activity through heatmap generation.

**Technologies:**

`Python` `YOLO` `OpenCV` `Computer Vision` `ByteTrack`

**Key Features:**

* Person detection
* Multi-object tracking
* Crowd activity analysis
* Centroid-based movement analysis
* Heatmap generation
* Activity visualization
* Real-time video analysis

### 3. Indian Sign Language to Text & Speech - FingerTalk

An AI-based system designed to recognize Indian Sign Language gestures and translate them into text and speech.

**Technologies:**

`Python` `TensorFlow` `Keras` `OpenCV` `MediaPipe`

**Key Features:**

* Indian Sign Language recognition
* Deep learning-based image classification
* Hand landmark detection
* Real-time camera integration
* Gesture-to-text conversion
* Text-to-speech functionality
* Data augmentation and model training

### 5. QRStream

A QR-based file transmission system that enables data to be divided into chunks, encoded into QR codes, displayed sequentially, and reconstructed by a receiver application.

**Key Features:**

* File chunking
* QR code generation
* Sequential QR transmission
* Camera-based QR scanning
* Packet reconstruction
* File recovery
* Python sender
* Android receiver

## ⚙️ Run Locally

You can run the portfolio locally without installing any framework or package.

### 1. Clone the repository

```bash
git clone https://github.com/wSubham/wSubham.github.io.git
```

### 2. Enter the project directory

```bash
cd wSubham.github.io
```

### 3. Open the website

Simply open:

```text
index.html
```

in your browser.

Alternatively, you can use the **Live Server** extension in Visual Studio Code for local development.
