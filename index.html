AI Weapon-Detection and Multi-Camera Surveillance

Developed a real-time AI-powered multi-camera surveillance system for detecting pistols and knives, tracking multiple individuals, and performing cross-camera person re-identification. Integrated YOLO-based detection and pose estimation with ByteTrack and DeepSORT for robust object tracking, while OSNet was used for person re-identification across different camera views. The system also incorporates weapon–person association, automated suspect identification, evidence logging, and suspect snapshot generation for intelligent security monitoring.

QR Stream

QRStream is an offline cross-platform file transfer system that transfers any file from a desktop computer to an Android device using dynamic QR codes.Unlike conventional transfer methods, QRStream requires no Internet connection, Wi-Fi, Bluetooth, USB data transfer, or cloud service. The sender continuously displays QR codes containing encoded file packets, while the Android application scans, validates, reconstructs, and stores the original file.
